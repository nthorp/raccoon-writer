The first release of **Raccoon Writer**, a Mac app that writes `.iso` and `.img` disk images to USB drives and SD cards, for example to make a bootable Linux installer.

Pick an image, pick a drive, confirm, and Raccoon Writer writes the image, reads it back to verify it, and ejects the drive.

## Install

Download `RaccoonWriter.dmg` below, open it, and drag Raccoon Writer to Applications.

- macOS 14 or later, on Apple Silicon or Intel (universal app).
- Signed with a Developer ID and notarized by Apple.
- To check the download: `shasum -a 256 RaccoonWriter.dmg` should match `RaccoonWriter.dmg.sha256`.

## Before you write

**Writing erases the entire drive you pick**: every partition and volume on it. The app helps you pick the right one:

- The boot disk and internal disks are never listed. An SD card in a Mac's built-in slot is the one exception.
- Each drive shows its name, size, volume names and `/dev/diskN`. Drives over 500 GB are marked "Large drive".
- A confirm screen and an administrator password come before anything is written. Right after the password, the drive is checked again, and the write stops if it changed or disappeared.

## Known limitations

- Only images made to boot from USB work (hybrid ISOs: most Linux distributions, and raw `.img` files). Windows installer ISOs are not supported.
- Compressed images (`.xz`, `.gz`, `.zip`) must be decompressed first.
- One drive at a time, and a password prompt on every write.
- Not yet tested on an Intel Mac.

The full list is in the [README](https://github.com/nthorp/raccoon-writer#known-limitations).

`RaccoonWriter-1.0.0.dSYM.zip` contains debug symbols for reading crash reports. You don't need it to use the app.
